2026-10-23：已完成数据审计、固定划分、T0 Softmax 基线与 T1 线性 SVM 对照。实现和结果见 [首轮实验记录](experiments/softmax-baseline.md)及 [SVM 对照实验](experiments/svm-comparison.md)。CNN 训练、恢复、评估和单图预测流程已实现，D0 基线训练进行中；运行方式见 [CNN 训练与复现](cnn-workflow.md)。原始测试集尚未评价。

## 1. 目标与范围

在课程提供的 CUB-200 鸟类数据集上完成两项分类任务，并保存可复现的训练配置、模型和评价结果。

| 项目 | 要求 |
| --- | --- |
| 任务一 | 固定选取 10 类，用传统模式识别方法分类，占 3 分 |
| 任务二 | 使用原始图像从零训练深度神经网络，占 7 分 |
| 评分 | 性能 2 分、代码 5 分、报告 3 分 |
| 报告 | 3000 字以内，包含代码功能、运行过程、方案设计和结果分析 |
| 深度学习限制 | 禁止预训练权重，自行实现整体流程，不能使用现成训练仓库 |

任务一允许使用教师提供的特征。仅任务一明确允许缩减为 10 类，任务二按全部 200 类执行。具体样本数量以数据审计结果为准。

项目先完成基础方法与复现流程，再进行受控对照实验。性能结论依据实测结果，不预设准确率目标或改进收益。截止日期、提交格式与权重文件要求以课程平台通知为准。

## 3. 数据与评价协议

### 数据审计

1. 统计类别、每类样本数、图像尺寸和损坏文件。
2. 核对 `.jpg` 与 `.pt` 文件对应关系，检查特征类型、维数和非有限值。
3. 建立统一类别映射，从排序后的类别列表按固定种子抽取 10 类并保存名单。
4. 检查跨划分的完全重复图像，记录异常，不自行改动教师划分。
5. 保存样本清单、数据版本及审计结果。

提供特征的维数和来源待数据检查后记录。方法不依赖作业说明之外的框、关键点或属性标注。

### 划分与模型选择

- 从原始 `train/` 按类别分层划出约 15% 作为内部验证集，其余用于拟合。
- 原始 `val/` 是测试集，不参与超参数选择、早停或检查点选择。
- 同一任务的对照实验使用相同类别、划分和评价方式。
- 标准化和 PCA 仅在当前拟合子集上学习参数。
- 验证、测试使用确定性预处理；神经网络使用评估模式。
- 首轮实验直接评估内部验证选出的检查点。使用完整原始训练集重训时，先冻结配置和训练轮数，再集中测试。

### 指标与结果

主指标为 Top-1 准确率，同时记录正确数、样本总数、训练时间、参数量及逐图预测。训练曲线、混淆矩阵和错误样例用于解释结果。

10 类与 200 类结果分别报告，不直接据此比较传统方法和深度学习的优劣。教师提供特征的来源差异也应在讨论中说明。

## 4. 传统分类

### Softmax 基线

流程：提供特征 → 标准化 → 线性变换 → Softmax → 类别预测。

使用 NumPy 实现稳定 Softmax、多类交叉熵、L2 正则化、梯度、参数更新和预测。先核验小规模数值梯度与损失下降，再开展正式训练。标准化参数、分类权重和类别映射共同保存。

先确定稳定学习率，再比较正则化强度 `{0, 1e-4, 1e-3, 1e-2}`，全部参数通过内部验证选择。

### SVM 对照

采用线性软间隔 SVM，通过一对一策略构建 45 个二分类器。自行实现核矩阵、对偶目标与约束、支持向量筛选、偏置、判别函数和多类投票；二次规划交给通用求解器。

检查求解器状态、数值容差及没有自由支持向量时的偏置计算。初始比较 `C ∈ {0.1, 1, 10}`。在验证结果支持进一步探索时加入少量 RBF 配置。

### PCA 扩展

仅在特征维数和基础结果表明存在分析价值时加入 PCA。自行实现中心化、主方向选择和投影，底层矩阵分解使用数值库。保留维数不得超过拟合数据的有效秩。

## 5. 深度学习分类

### 基础 CNN

初始输入尺寸为 `160×160`，使用 4 个卷积阶段，通道数为 `32 → 64 → 128 → 256`。各阶段由小卷积核、BN、ReLU 和下采样组成，末端为全局平均池化与 200 类线性分类头。层数和步幅在实现时固定并保存到配置。

初始训练设置：

- 随机初始化，交叉熵损失。
- SGD，momentum 0.9，weight decay 1e-4。
- 余弦学习率衰减；初始学习率通过短训练确定。
- batch size 为 32 或 64，依据设备实测确定。
- 正式预算暂定 80–120 epoch，依据单轮耗时和内部验证曲线调整。

以上配置为实验起点，尚未验证。交叉熵直接接收 logits；类别预测取最高得分。

### 数据增强

固定预处理构成基础配置。增强配置加入水平翻转、保守随机裁剪和轻微颜色扰动，其他设置保持一致。保存增强样例，检查鸟体可见性与细粒度判别信息是否保留。

### 残差结构

自行实现残差块与必要的投影支路。在普通 CNN 与残差 CNN 间尽量匹配深度、通道、输入尺寸和训练配置，同时报告参数量差异。

残差连接与常规增强属于已有方法的应用。贡献表述以实际假设、对照实验和证据为依据。

### 算力预算

先完成小批量前向、反向及单轮计时，再确定正式训练预算。资源不足时减少候选实验、batch size 或模型宽度；保持完整 200 类正式任务。小样本实验仅用于调试。

## 6. 实验矩阵

| 编号 | 配置 | 分析问题 | 范围 |
| --- | --- | --- | --- |
| T0 | 提供特征 + Softmax | 线性分类基线 | 必做 |
| T1 | 相同特征 + 线性 SVM | 最大间隔目标的影响 | 核心对照 |
| D0 | CNN + 基本预处理 | 从零训练基线 | 必做 |
| D1 | D0 + 数据增强 | 泛化能力的变化 | 核心对照 |
| D2 | D1 的相近结构加入残差连接 | 训练稳定性和准确率变化 | 核心对照 |
| E1 | PCA、RBF 核或更高分辨率之一 | 由已有结果确定的问题 | 扩展 |

先使用固定种子筛选配置。算力允许时，对关键对照使用相同的 3 个训练种子复跑，报告均值和标准差。只有单次实验时，明确结果的随机性限制。测试结果不用于追加调参。

## 7. 工程组织

以下为待实现的目录结构：

```text
configs/                  实验配置
splits/                   类别映射、类别名单和数据划分
src/
  data.py                 图像与特征加载
  traditional/            Softmax、SVM、可选 PCA
  models/                 普通 CNN 与残差 CNN
  train_traditional.py     传统方法训练
  train_cnn.py             深度网络训练
  evaluate.py              统一评价
  predict.py               单张 RGB 图像推理
  utils.py                 日志、随机种子、保存与恢复
outputs/                  实验日志、模型、预测和图表
report/                   报告源码与最终文档
```

任务一输入提供特征；单张图像直接分类由任务二模型提供。每次实验保存配置快照、划分、随机种子、环境与代码版本、训练曲线、检查点和预测结果。

断点恢复保存模型、优化器、调度器、训练轮次及相关随机状态。跨设备数值差异如实记录。原始数据、环境、缓存和大体积训练产物不进入 Git；交付文件按课程通知整理。
