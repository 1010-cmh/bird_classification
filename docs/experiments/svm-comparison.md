# 线性 SVM 与 Softmax 对照

实验日期：2026-10-23。任务一固定 10 类，输入为教师提供的 384 维特征。使用与首轮 Softmax 完全一致的类别顺序及划分：442 张拟合样本、78 张内部验证样本。59 张最终测试样本未用于性能评价。

## 方法与实现边界

每对类别训练一个软间隔 SVM，10 类共 45 个二分类器。较小标签编码为 -1，较大标签编码为 +1。标准化参数仅由拟合子集估计。

二分类对偶问题写为最小化 `0.5 αᵀQα − 1ᵀα`，其中 `Qᵢⱼ = yᵢyⱼK(xᵢ,xⱼ)`，约束为 `0 ≤ αᵢ ≤ C`、`yᵀα = 0`。CVXOPT 负责求解这一约束二次规划；核矩阵、目标与约束构造、支持向量筛选、偏置、判别函数和多分类投票均由项目代码实现。

有自由支持向量时，对 `yᵢ − Σⱼ αⱼyⱼK(xⱼ,xᵢ)` 求均值得到偏置。没有自由支持向量时，由边界样本的 KKT 不等式构造偏置上下界并取中点。预测采用两两投票，平票时使用有界决策分数，完全相同时取较小类别标签。

## 参数和数值检查

比较线性核 `C ∈ {0.1, 1, 10}`。按内部验证准确率选择模型，平局时选择较小的 C。此规则在实验前确定。

CVXOPT 容差：`abstol=1e-12`、`reltol=1e-10`、`feastol=1e-10`，最多 100 次迭代。支持向量阈值为 `min(1e-7, C × 1e-5)`。模型接受条件还包括原始解等式/边界残差不超过 `1e-6`、筛选后等式残差不超过 `1e-5`、最大 KKT 残差不超过 `1e-3`。

本轮 135 个二分类器均返回 optimal 并通过上述检查。筛选后的最大等式残差为 `5.65e-09`，记录到的最大原始/对偶目标差为 `3.91e-05`。求解器的 optimal 状态是数值收敛判定，不表示精确算术下的零残差。

## 实验结果

| C | 训练准确率 | 内部验证准确率 | 支持向量累计出现次数 | 最大 KKT 残差 |
| --- | --- | --- | --- | --- |
| 0.1 | 100.00% | 100.00% | 1117 | 3.06e-06 |
| 1 | 100.00% | 100.00% | 1117 | 1.22e-06 |
| 10 | 100.00% | 100.00% | 1117 | 1.64e-06 |

支持向量数量是 45 个二分类器的计数之和，同一样本参与多个分类器时重复计数。按既定规则选择 `C=0.1`。

| 方法 | 拟合样本 | 内部验证正确数 | 内部验证准确率 |
| --- | --- | --- | --- |
| Softmax，L2=0 | 442 | 78/78 | 100% |
| 线性 SVM，C=0.1 | 442 | 78/78 | 100% |

两种方法在当前固定划分上得到相同的准确率，未观察到最大间隔目标带来的准确率收益。三组 C 的预测与支持向量计数相同，当前范围内模型对 C 不敏感。结果支持给定特征在所选类别上易于线性分类这一观察，不能推广到其他类别划分或从零训练的 200 类图像分类。

内部验证仅 78 张，且参与参数选择；本轮没有其他数据划分的重复实验。达到 100% 不能替代独立测试，也不据此继续挑选类别或调整划分。

## 验证与运行

```bash
python -m pip install -r requirements.txt
python -m pytest -q
python -m src.train_svm --data-dir data --output-dir outputs/svm-linear
python -m src.evaluate --data-dir data \
  --model outputs/svm-linear/model.npz \
  --split internal_val --output-dir outputs/svm-linear-validation
```

共 34 项测试通过。SVM 数值测试包含解析解、无自由支持向量、相同特征的矛盾标签、非收敛拒绝、RBF 的 XOR 分类、多分类投票及保存恢复。流程测试移除最终测试数据后仍可完成训练和内部验证。

真实模型重新加载后，78 张逐图预测与训练阶段完全一致。统一评估器也验证了首轮 Softmax 检查点的兼容性。RBF 仅完成单元测试，本轮没有在课程数据上开展 RBF 实验。
