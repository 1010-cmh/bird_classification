# CUB-200 鸟类图像分类

《模式识别与机器学习》课程大作业，包含给定特征上的传统分类和原始 RGB 图像上的深度学习分类。

## 任务

| 任务 | 数据范围 | 输入 | 方法 |
| --- | --- | --- | --- |
| 传统分类 | 固定的 10 个类别 | 教师提供的特征向量 | Softmax 回归、支持向量机 |
| 深度学习分类 | 完整 200 个类别 | 原始 RGB 图像 | 从零训练的卷积神经网络 |

主要评价指标为测试集 Top-1 准确率。两项任务的类别数和输入表示不同，结果分别报告。

## 数据约定

使用课程提供的 CUB-200 数据版本，不与其他公开划分混用。数据集不纳入版本控制。

```text
data/
  train/
    <class>/
      <sample>.jpg
      <sample>.pt
  val/
    <class>/
      <sample>.jpg
      <sample>.pt
```

课程数据中的 `val/` 为测试集。调参和检查点选择使用从 `train/` 内划分的内部验证集，测试集仅用于最终评价。

## 实现约定

- 传统分类的预处理、损失、训练流程和预测逻辑自行实现；SVM 对偶问题可调用通用二次规划求解器。
- 深度网络使用 PyTorch 基础组件，自行编写数据集、模型、训练和推理代码，不使用预训练权重或现成训练仓库。
- 数据划分、类别映射、随机种子和实验配置均保存记录。
- 环境依赖、运行命令和复现步骤随实现进度补充。
